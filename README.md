# Self-Adaptive-Pantograph-Monitoring-System-
Project Overview

The Smart Pantograph Wear Protection System is an IoT-based railway monitoring project designed to monitor the condition of railway pantographs.

Problem Statement

Traditional pantograph inspection depends mainly on periodic manual inspections. This can delay the identification of abnormal wear and operating conditions.

Objectives

- Monitor pantograph carbon strip wear.
- Measure contact pressure.
- Monitor temperature variations.
- Process sensor data using ESP8266.
- Transmit monitoring data through Wi-Fi.

Hardware Components

1. ESP8266 Wi-Fi Controller
2. Wear Sensor
3. Pressure Sensor
4. Temperature Sensor
5. Power Supply

Working Principle
  The wear sensor monitors the carbon strip condition. The pressure sensor measures contact pressure, while the temperature sensor monitors temperature variations.
  The ESP8266 collects and processes the sensor readings and transmits the monitoring information through Wi-Fi.

Communication
  Wi-Fi communication using ESP8266.

Applications

- Railway pantograph condition monitoring
- Railway maintenance support
- Electrical equipment monitoring

Future Scope

- GPS-based location monitoring
- Cloud-based data storage
- Railway control-room integration
- Advanced condition monitoring

Project Domain
